# Token Forge

Turn design tokens into Figma variables with collections and modes.

## How it works

1. **Paste or import file** — JSON, CSS, or Material Theme export
2. **Analyze** — auto-detected tokens via collections and modes
3. **Import** — one click into Figma Variables

## What it supports

- DTCG, flat JSON, CSS custom properties, Material Theme formats
- Collections: create new or import to existing
- Aliases, Modes, Scope mapping
- Replace / Merge
